# Инструкция по исправлению ошибки с notifications

## Ошибка:
```
Error: Failed to run sql query: ERROR: 42703: column "is_read" does not exist
```

## Решение:

### Шаг 1: Выполнить git pull на PythonAnywhere
```
cd ~/mysite
git pull
```

### Шаг 2: Выполнить новую миграцию на Supabase
1. Открыть Supabase Dashboard → SQL Editor
2. Вставить содержимое файла `migrations/add_max_workers.sql`
3. Выполнить

### Что исправлено:
- Добавлена проверка на существование столбца `is_read` перед добавлением
- Использован блок `DO $$ BEGIN ... END $$` для безопасного добавления столбца
- Индекс `idx_notifications_read` теперь создается только если столбец был добавлен

### Если таблица notifications уже существует:
Миграция автоматически обнаружит существующую таблицу и добавит только недостающие столбцы.

### Если возникнут другие ошибки:
1. Проверить структуру таблицы:
```sql
SELECT * FROM information_schema.columns WHERE table_name = 'notifications';
```
2. Удалить таблицу и создать заново (если пуста):
```sql
DROP TABLE IF EXISTS notifications;
```
