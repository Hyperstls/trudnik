=========================================
ИНСТРУКЦИЯ: Обновление сайта на PythonAnywhere
=========================================

Проблема: Поле max_workers отсутствует в HTML на сервере.
Причина: Git pull не был выполнен в консоли PythonAnywhere.

Решение:
1. Зайдите на https://www.pythonanywhere.com
2. Откройте вкладку "Consoles"
3. В консоли Python 3 выполните:
   cd ~/mysite
   git pull
   touch /var/www/hyperstls_pythonanywhere_com_wsgi.py

4. Подождите 5-10 секунд и обновите страницу /job/new в браузере

После этого поле "Максимум работников" должно появиться.
