# ИНСТРУКЦИЯ ПО ДЕПЛОЮ max_workers

## Проблема
Поле `max_workers` не отображается на странице `/job/new` на PythonAnywhere.

## Причина
На сервере PythonAnywhere не обновлён шаблон `templates/job_new.html`.

## Решение (РУЧНОЕ ОБНОВЛЕНИЕ)

1. Откройте https://www.pythonanywhere.com
2. Зайдите в аккаунт
3. Перейдите на вкладку **"Consoles"** (вверху экрана)
4. Нажмите **"+ Start a new console"** и выберите **"Bash"**
5. В консоли выполните следующие команды по порядку:

```bash
cd ~/mysite
git pull
touch /var/www/hyperstls_pythonanywhere_com_wsgi.py
```

6. Подождите 5-10 секунд после выполнения команд
7. Обновите страницу `/job/new` в браузере (используйте **Ctrl+Shift+R** для полной очистки кэша)

## Проверка

После обновления на странице `/job/new` должно быть видно поле:
```
Максимум работников
[1]
Сколько работников нужно для этого задания
```

## Дополнительная информация

- Коммиты с изменениями уже отправлены на GitHub
- Локальный файл `templates/job_new.html` содержит поле `max_workers`
- Маршруты в `app.py` уже поддерживают `max_workers`
- Миграция базы данных находится в `migrations/add_max_workers.sql`

## Почему auto_fix_agent.py не работает?

`auto_fix_agent.py` использует API консоли PythonAnywhere, который требует платного тарифа. 
На бесплатном тарифе удалённый доступ к консоли через API недоступен.
