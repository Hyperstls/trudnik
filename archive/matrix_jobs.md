# Матрица статусов и доступных операций в приложении «Трудник»

## 1. Статусы задания (jobs.status)

| Статус | Описание | Кто может видеть |
|--------|----------|------------------|
| `open` | Задание открыто для откликов | Все |
| `in_progress` | Есть принятые отклики, смена ещё не началась | Все |
| `active` | Смена активна (трудник отметил чек-ин) | Все |
| `payment_pending` | Смена завершена, ожидает подтверждения оплаты | Все |
| `paid` | Оплата подтверждена обеими сторонами | Все |
| `completed` | Смена завершена полностью (после paid) | Все |
| `cancelled` | Задание отозвано работодателем | Все |

---

## 2. Статусы смены (shifts.status)

| Статус | Описание |
|--------|----------|
| `pending` | Смена создана, но ещё не началась |
| `active` | Трудник отметил чек-ин (начал смену) |
| `payment_pending` | Трудник завершил смену, ожидает оплаты |
| `paid` | Оплата подтверждена обеими сторонами |
| `completed` | Смена полностью завершена |
| `disputed` | Открыт спор по смене |

---

## 3. Матрица доступных операций для работодателя

### 3.1. Операции с заданием (my_jobs.html)

| Статус задания | Доступные операции | Условия |
|----------------|-------------------|---------|
| `open` | • Дублировать<br>• Отозвать (cancel)<br>• Удалить<br>• Принимать отклики | Нет ограничений |
| `in_progress` | • Дублировать<br>• Удалить | Есть принятые отклики |
| `active` | • Дублировать<br>• Удалить | Смена активна |
| `payment_pending` | • Дублировать<br>• Удалить<br>• Подтвердить оплату | Ожидает оплаты |
| `paid` | • Дублировать<br>• Удалить<br>• Оценить трудника | Оплата подтверждена |
| `completed` | • Дублировать<br>• Удалить | Смена завершена |
| `cancelled` | • Вернуть (restore)<br>• Дублировать<br>• Удалить | Задание отозвано |

---

### 3.2. Операции с откликами (my_applications.html)

| Статус отклика | Действия работодателя | Что происходит |
|----------------|----------------------|----------------|
| `pending` (ожидает) | • **Принять** (accept)<br>• **Отклонить** (reject)<br>• Раскрыть контакты (оплата) | При принятии:<br>• status → `accepted`<br>• Создаётся смена (shift)<br>• jobs.current_workers++<br>• jobs.status → `in_progress` |
| `accepted` (принят) | • **Отклонить** (reject)<br>• Открыть чат<br>• Контакты открыты | При отклонении:<br>• status → `rejected`<br>• jobs.current_workers--<br>• Смена удаляется<br>• contacts_paid → false |
| `rejected` (отклонён) | • **Повторно принять** (reopen→accept)<br>• Открыть чат | При повторном принятии:<br>• status → `pending` → `accepted`<br>• Создаётся новая смена |

---

## 4. Матрица доступных операций для трудника

### 4.1. Операции с заданием (index.html, job_detail.html)

| Статус задания | Действия трудника | Условия |
|----------------|------------------|---------|
| `open` | • **Откликнуться** (apply)<br>• В избранное<br>• Написать работодателю | Если ещё не откликался<br>и current_workers < max_workers |
| `in_progress` | • В избранное<br>• Написать работодателю | Нельзя откликнуться |
| `active` | • В избранное<br>• Написать работодателю | Нельзя откликнуться |
| `payment_pending` | • В избранное<br>• Написать работодателю | Нельзя откликнуться |
| `paid` | • В избранное<br>• Написать работодателю<br>• Оценить работодателя | Нельзя откликнуться |
| `completed` | • В избранное<br>• Написать работодателю | Нельзя откликнуться |
| `cancelled` | • В избранное<br>• Написать работодателю | Нельзя откликнуться |

---

### 4.2. Операции со сменой (shifts.html)

| Статус смены | Действия трудника | Что происходит |
|--------------|------------------|----------------|
| `pending` | • **Отметить начало** (checkin) | • worker_checkin = true<br>• start_time = now<br>• shifts.status → `active`<br>• jobs.status → `active` |
| `active` | • **Завершить** (complete) | • worker_complete = true<br>• complete_time = now<br>• shifts.status → `payment_pending`<br>• jobs.status → `payment_pending` |
| `payment_pending` | • **Оплату получил** (confirm_worker)<br>• **Спор** (dispute) | При подтверждении:<br>• worker_payment_confirmed = true<br>• Если employer тоже подтвердил → status → `paid` |
| `paid` | • **Оценить работодателя** | Оценка 1-5 звёзд + комментарий |
| `completed` | • Просмотр | Нет доступных действий |
| `disputed` | • Просмотр | Ожидание решения админа |

## 5. Матрица переходов статусов

### 5.1. Задание (jobs)

```
open ──[принят отклик]──> in_progress ──[чек-ин]──> active
  │                            │                         │
  │                            │                         │
  └──[отозвано]──> cancelled   └──[все отклонены]──> open  └──[завершена]──> payment_pending
                                                              │
                                                              │
                                                              └──[подтверждена оплата]──> paid
                                                                                           │
                                                                                           │
                                                                                           └──[оценки]──> completed
```

### 5.2. Смена (shifts)

```
pending ──[чек-ин трудника]──> active ──[завершение трудником]──> payment_pending
                                                                        │
                                                                        │
                     ┌──────────────────────────────────────────────────┴──────────────────────────────────────────────────┐
                     │                                                                                                          │
                     │                                                                                                          │
          [подтвердил работодатель]                                                                                 [подтвердил трудник]
                     │                                                                                                          │
                     │                                                                                                          │
                     └──────────────────────────────────> paid <───────────────────────────────────────────────────────────────┘
                                                                        │
                                                                        │
                                                                        └──[оценки]──> completed
```

## 6. Условия блокировки операций

### 6.1. Для работодателя

| Операция | Условия блокировки |
|----------|-------------------|
| Принять отклик | • jobs.current_workers >= jobs.max_workers<br>• jobs.status не в (open, in_progress) |
| Отклонить принятого | • Если до начала смены < 12 часов (предупреждение) |
| Отозвать задание | • Если есть активные смены (status = active) |
| Удалить задание | • Если есть принятые отклики (только с подтверждением) |

### 6.2. Для трудника

| Операция | Условия блокировки |
|----------|-------------------|
| Откликнуться | • jobs.current_workers >= jobs.max_workers<br>• jobs.status != open<br>• Уже откликался (already_applied = true) |
| Отозвать отклик | • Только если status = pending (ещё не принят) |
| Отметить начало | • Только если shifts.status = pending<br>• Только если session.user_id == shift.worker_id |
| Завершить смену | • Только если shifts.status = active<br>• Только если !worker_complete |

## 7. Контакт-пейволл (оплата за раскрытие контактов)

| Ситуация | Доступ к контактам |
|----------|-------------------|
| Отклик `pending` | ❌ Скрыты<br>✅ После оплаты (290 ₽) |
| Отклик `accepted` | ✅ Открыты автоматически<br>(при принятии contact_paid = true) |
| Отклик `rejected` | ❌ Скрыты<br>(contact_paid сбрасывается) |

---

## 8. Массовые операции

### 8.1. Работодатель (my_applications.html)

| Операция | Доступна для статусов |
|----------|----------------------|
| Принять выбранные | `pending` |
| Отклонить выбранные | `pending`, `accepted` |
| Повторно принять | `rejected` |

### 8.2. Трудник (index.html)

| Операция | Доступна |
|----------|----------|
| Откликнуться на выбранные | Задания со status = `open`<br>где ещё не откликался |
| Отозвать выбранные | Задания, где отклик в status = `pending` |
