# OPTIMIZATION PLAN for app.py

## Issues Found:

### 1. Duplicate routes (job_new and create_job)
Both routes `/job/new` and `/create-job` do the same thing - create jobs with max_workers support.
Only ONE route should exist.

### 2. Redundant code in role_required decorator
The decorator doesn't check if the response is empty before accessing data[0].

### 3. Inconsistent error handling
Some functions use `except:`, others use `except Exception as e:`.

### 4. Unused imports
`subprocess` and `uuid` are imported but `uuid` is not used in most of the file.

### 5. Large file
File has 1400+ lines which makes it hard to maintain.

## Recommendations:

1. **Remove duplicate `/create-job` route** - keep only `/job/new`
2. **Fix role_required decorator** - add empty check
3. **Standardize error handling** - use `except Exception as e`
4. **Remove unused imports** - remove `subprocess`
5. **Split file** - move functions to separate modules (jobs.py, auth.py, shifts.py)
