### Шаг 2: Готовый промт для Kilo Code
Скопируйте текст ниже, вставьте свои данные в места, отмеченные `[КАВЫЧКАМИ]`, и отправьте это сообщение вашему ИИ-агенту Kilo Code:

```text

Вводные данные:
- Целевой сайт: [ВСТАВЬТЕ СЮДА URL САЙТА, например: https://www.mvideo.ru]

- Мой API-ключ DeepSeek: [ВСТАВЬТЕ СЮДА ВАШ API-КЛЮЧ]

ШАГ 2: Написание кода.
Напиши полный, готовый к запуску Python-скрипт. 
    Важные требования к коду:
    - Используй `undetected-chromedriver` вместо обычного Selenium, чтобы сайт не блокировал нас как бота.
    - Перед отправкой HTML в DeepSeek, очисти его с помощью BeautifulSoup (оставь только текст и ссылки), чтобы сэкономить токены и не превысить лимиты.

    - Добавь в код обработку ошибок трёх категорий раздельно: (а) сетевые ошибки (`ConnectionError`, таймауты Selenium), (б) отсутствие элемента на странице (`NoSuchElementException` — тогда пробуй запасной селектор), (в) ошибки API DeepSeek (неверный ключ, превышение лимита токенов, rate limit). ШАГ 4: Результат.
```

### Шаг 3: Как общаться с агентом дальше (советы для новичка)

1. **Не бойтесь ошибок**. Если агент выдаст красную ошибку в терминале, просто скопируйте эту ошибку и напишите ему: *"Выдало такую ошибку, исправь это"*. Современные ИИ-агенты отлично умеют чинить свой же код.
2. **Если агент "застрял"**. Если он пытается сделать что-то слишком сложное, скажите: *"Давай упростим. Пока просто открой браузер и выведи заголовок страницы, без DeepSeek"*. А потом усложняйте задачу пошагово.
3. **Безопасность**: Никогда не публикуйте свой API-ключ DeepSeek в открытых чатах или форумах. Вводите его только в приватном окне вашего ИИ-агента.

### Почему этот промт сработает?
- Он задает **роль** (эксперт, который объясняет просто).
- Он дает **четкий план** (Шаг 1, Шаг 2 и т.д.), не давая агенту галлюцинировать.
- Он сразу решает главную техническую проблему новичков (блокировки сайтов), требуя использовать `undetected-chromedriver`.
- Он перекладывает всю ответственность за ошибки на агента, требуя от него самостоятельной отладки.
