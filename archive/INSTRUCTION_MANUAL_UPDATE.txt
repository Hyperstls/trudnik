ПРОБЛЕМА:
Поле max_workers не отображается на странице /job/new
Причина: git pull не выполнен на PythonAnywhere

ПОЧЕМУ auto_fix_agent.py НЕ РАБОТАЕТ:
- auto_fix_agent.py использует API консоли PythonAnywhere
- Для работы API консоли требуется платный тариф
- Бесплатный тариф не позволяет удалённый доступ к консоли

РЕШЕНИЕ: РУЧНОЕ ОБНОВЛЕНИЕ

1. Откройте https://www.pythonanywhere.com
2. Зайдите в аккаунт
3. Перейдите на вкладку "Consoles" (вверху)
4. Нажмите "Bash" или "Python 3" чтобы открыть консоль
5. В консоли выполните следующие команды:

   cd ~/mysite
   git pull
   touch /var/www/hyperstls_pythonanywhere_com_wsgi.py

6. Подождите 5-10 секунд
7. Обновите страницу /job/new в браузере (Ctrl+F5)

ПОСЛЕ ЭТОГО:
- Поле "Максимум работников" появится в форме
- Можно будет создавать задания с max_workers
- Счётчик current_workers будет обновляться при откликах
