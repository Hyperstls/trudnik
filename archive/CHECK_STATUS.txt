## Почему сайт не обновляется?

`auto_fix_agent.py` использует PythonAnywhere API для отправки команд в консоль:
```python
commands = "cd ~/mysite && git pull && touch /var/www/hyperstls_pythonanywhere_com_wsgi.py\n"
```

Однако на бесплатном тарифе PythonAnywhere:
1. API консоли может быть ограничен
2. Команда `git pull` может требовать интерактивного ввода (если используется HTTPS с паролем)
3. Консоль может не принимать команды без подтверждения пользователя

## РЕШЕНИЕ: РУЧНОЕ ОБНОВЛЕНИЕ

### Шаг 1: Откройте консоль на PythonAnywhere
1. Перейдите на https://www.pythonanywhere.com
2. Войдите в аккаунт
3. Нажмите **"Consoles"** (вверху экрана)
4. Нажмите **"+ Start a new console"**
5. Выберите **"Bash"**

### Шаг 2: Выполните команды обновления
В открывшейся консоли выполните по порядку:

```bash
cd ~/mysite
git pull
touch /var/www/hyperstls_pythonanywhere_com_wsgi.py
```

### Шаг 3: Проверьте результат
1. Подождите 5-10 секунд после выполнения команд
2. Откройте в браузере: https://hyperstls.pythonanywhere.com/job/new
3. Нажмите **Ctrl+Shift+R** для полной очистки кэша
4. Проверьте наличие поля "Максимум работников"

### Шаг 4: Проверка наличия поля
В HTML коде страницы должна быть строка:
```html
<input type="number" name="max_workers" value="1" min="1" ...>
```

## Дополнительные команды для отладки

Если поле всё ещё не отображается, выполните в консоли PythonAnywhere:

```bash
# Проверить наличие файла

# Проверить содержимое файла

```
