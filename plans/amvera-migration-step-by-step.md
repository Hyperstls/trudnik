## Шаг 1: Создать Managed PostgreSQL

### Где: Amvera → вкладка «Сервисы» → «Базы данных» → «Managed PostgreSQL»

### Что нажать
1. Нажмите **«Создать сервис»**
2. Выберите тариф **«Начальный»** (~500 ₽/мес)
3. Заполните поля:

| Поле | Значение |
|------|----------|
| **Имя сервиса** | `trudnik-db` |
| **Имя БД** | `trudnik` |
| **Имя пользователя** | `trudnikapp` |
| **Пароль** | ВАШ_ПАРОЛЬ
| **Superuser Access** | ВКЛЮЧИТЕ (обязательно) | Пароль: ВАШ_ПАРОЛЬ_СУПЕРПОЛЬЗОВАТЕЛЯ
| **Количество реплик** | 1 (достаточно для старта) |

4. Нажмите **«Создать»** и дождитесь статуса **«Активен»** (~3–5 минут)

### Что записать
После создания вы увидите три DNS-адреса. Запишите их:

```
amvera-...-cnpg-trudnik-rw   ← для чтения и записи (основной) = АДРЕС_ИЗ_ПАНЕЛИ_AMVERA
amvera-...-cnpg-trudnik-r    ← только для чтения = АДРЕС_ИЗ_ПАНЕЛИ_AMVERA
amvera-...-cnpg-trudnik-ro   ← только для чтения (запасной) = АДРЕС_ИЗ_ПАНЕЛИ_AMVERA
```

Нам нужен первый — **`-rw`** (read-write).

## Шаг 2: Создать PostgREST

### Где: Amvera → вкладка «Сервисы» → «Преднастроенные сервисы» → «Утилиты для баз данных» → «PostgREST»

### Что нажать
1. Нажмите **«Создать сервис»**
2. Заполните переменные окружения (4 штуки):

| Переменная | Значение | Пояснение |
|-----------|----------|-----------|
| `PGRST_DB_URI` | `postgresql://trudnikapp:ВАШ_ПАРОЛЬ@amvera-...-rw:5432/trudnik` | Подставьте пароль и DNS из Шага 1 |
| `PGRST_DB_SCHEMA` | `public` | Схема БД |
| `PGRST_DB_ANON_ROLE` | `web_anon` | Роль для неавторизованных запросов |
| `PGRST_JWT_SECRET` | СГЕНЕРИРУЙТЕ_НОВЫЙ_JWT_СЕКРЕТ_МИНИМУМ_32_СИМВОЛА |

3. Нажмите **«Создать»** и дождитесь статуса **«Активен»**

### Как сгенерировать JWT_SECRET
Откройте терминал (PowerShell) и выполните:
```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```
Скопируйте результат — это ваш `PGRST_JWT_SECRET`.

### Что записать
Внутренний DNS PostgREST:
```
amvera-...-postgrest-...
```

## Шаг 4: Установить расширения БД

После того как PostgreSQL активен, нужно установить расширения.

### Как: через pgAdmin (веб-интерфейс)

1. Amvera → «Преднастроенные сервисы» → «pgAdmin»
2. Создайте сервис pgAdmin, подключите его к `trudnik-db`
3. Откройте pgAdmin → найдите вашу БД `trudnik`
4. Откройте **Query Tool** (кнопка с иконкой SQL)
5. Выполните по очереди:

```sql
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS pg_trgm;
```

6. Проверьте, что расширения установлены:
```sql
SELECT extname FROM pg_extension;
```

Должны появиться: `postgis`, `pgcrypto`, `pg_trgm`.

## Шаг 8: Настроить уведомления (email)

### Текущее состояние
Проект **уже умеет отправлять email**. Всё что нужно — правильно заполнить SMTP-переменные в `.env.amvera`.

Код для отправки уже написан в `app/services/email_service.py` и вызывается через Celery-задачи (`app/tasks/email_tasks.py`).

### Что нужно сделать вам

#### Вариант А: Яндекс.Почта (рекомендуется)

1. Зайдите в [Яндекс.Почту](https://mail.yandex.ru)
2. Создайте отдельный ящик для уведомлений, например `notifications@yandex.ru`
3. Зайдите в **Настройки** → **Безопасность** → **Пароли приложений**
4. Создайте пароль приложения для почтового клиента
5. Скопируйте сгенерированный пароль — он понадобится для `.env.amvera`

Заполните в `.env.amvera`:
```
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=587
SMTP_USER=notifications@yandex.ru
SMTP_PASSWORD=ваш_пароль_приложения
SMTP_FROM_EMAIL=notifications@yandex.ru
SMTP_FROM_NAME=Trudnik
```

#### Вариант Б: Gmail

1. Зайдите в [Google Аккаунт](https://myaccount.google.com)
2. **Безопасность** → **Двухфакторная аутентификация** (включите, если выключена)
3. **Пароли приложений** → создайте пароль для «Почта»
4. Скопируйте 16-значный пароль

Заполните в `.env.amvera`:
```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=ваш_email@gmail.com
SMTP_PASSWORD=ваш_16_значный_пароль_приложения
SMTP_FROM_EMAIL=ваш_email@gmail.com
SMTP_FROM_NAME=Trudnik
```

### Важные замечания
- **Не используйте** основной пароль от почты — только пароль приложения
- **Не коммитьте** пароли в репозиторий — они хранятся только в `.env.amvera` (который в `.gitignore`)
- Письма отправляются **асинхронно** через Celery — пользователь не ждёт отправки
- Дневной лимит: 1000 писем (настраивается в `SMTP_DAILY_LIMIT`)

## Часто задаваемые вопросы

### Что делать, если письма не отправляются?
1. Проверьте, что пароль приложения скопирован без ошибок
2. Убедитесь, что в настройках почты разрешён доступ через SMTP
3. Для Gmail: включена ли двухфакторная аутентификация?
4. Проверьте логи: Amvera → «Логи» → найдите ошибки `SMTP`

### Что делать, если карта Яндекс пустая?
1. Проверьте `YANDEX_MAPS_API_KEY` в `.env.amvera`
2. Откройте консоль браузера (F12) — посмотрите ошибки CSP
3. Ключ должен быть формата: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`
