# План редизайна 5 страниц работодателя

## Исходные требования
Файл: `New_design.md` — редизайн страниц `/my-applications`, `/my-jobs`, `/favorites`, `/chats`, `/workers`

## Принципы
- **Mobile-first**: базовые классы для <640px, `md:` для 640-1024px, `lg:` для >1024px
- **Touch-friendly**: все кликабельные элементы ≥44×44px
- **Сохранение JS-логики**: все `data-*` атрибуты, `onclick`, обработчики остаются неизменными
- **Сохранение шаблонной логики**: Jinja2-циклы, условия, фильтры не ломаются
- **Без миграций БД**: изменения только в HTML/CSS (Tailwind), бекенд не трогаем

## Этап 1: `my_applications.html` (Отклики)

### Что меняем
| Было | Стало |
|------|-------|
| Карточка: свободный flow | Desktop: 2 колонки (инфо слева, статус+действия справа) |
| Кнопки действий: иконки в ряд | Desktop: вертикальный стек кнопок справа |
| Статус-бейджи: классы из base.html | Локальные цветные бейджи (yellow/green/red) |
| Чекбокс: сверху карточки | Слева от аватара, выровнен по центру |
| Масс-панель: снизу (fixed bottom) | Сверху (fixed top), появляется при выборе ≥1 |
| Mobile: аватар+имя+статус в 2 строки | Аватар 48px слева, имя+рейтинг+статус справа, навыки скрыты или 1-2 чипа |
| Контакт-пейволл: под действиями | Интегрирован в правую колонку (desktop) / раскрывается под карточкой (mobile) |

### Адаптивные брейкпоинты
- **Mobile (<640px)**: карточка 1 колонка, аватар 48px, действия — иконки в ряд
- **Tablet (640-1024px)**: карточка 1 колонка, действия в ряд, статус справа вверху
- **Desktop (>1024px)**: карточка 2 колонки через `lg:grid lg:grid-cols-[1fr_auto]`

### Статус-бейджи (новые)
- `pending`: `bg-yellow-100 text-yellow-800 border border-yellow-200`
- `accepted`: `bg-green-100 text-green-800 border border-green-200`
- `rejected`: `bg-red-100 text-red-800 border border-red-200`

## Этап 2: `my_jobs.html` (Мои задания)

### Что меняем
| Было | Стало |
|------|-------|
| Карточка: 1 колонка | Desktop: 3 колонки (название+дата+оплата / статистика+статус / действия) |
| Табы: pills с горизонтальным скроллом | Укрупнённые pills, активный с подчёркиванием `border-b-2` |
| Статусы: классы из base.html | Локальные: `open`=green, `in_progress`=blue, `completed`=gray, `cancelled`=red |
| Масс-панель: инлайн в форме | Плавающая сверху `sticky top-0 z-40` |
| Mobile: табы — горизонтальный скролл | Табы — горизонтальный скролл (сохранено) + dropdown-альтернатива |

### Адаптивные брейкпоинты
- **Mobile (<640px)**: 1 колонка, название+статус в строку, дата+оплата, статистика+действия
- **Tablet (640-1024px)**: 2 колонки через `md:grid md:grid-cols-[1fr_auto]`
- **Desktop (>1024px)**: 3 колонки через `lg:grid lg:grid-cols-[1fr_auto_auto]`

### Статусы заданий (новые)
- `open`: `bg-green-500 text-white`
- `in_progress`: `bg-blue-500 text-white`
- `completed`: `bg-gray-500 text-white`
- `cancelled`: `bg-red-400 text-white`

## Этап 4: `chats_list.html` (Чаты)

|------|-------|

## Этап 5: `workers.html` (Трудники)

### Что меняем
| Было | Стало |
|------|-------|
| Сетка: 1/2/3 колонки (уже адаптивно) | Обновлены отступы, тени, скругления, hover-эффекты |
| Карточка: кликабельна целиком | Сохранено, улучшен hover: `hover:shadow-lg hover:-translate-y-1` |
| Аватар: 56px | Desktop: 64px, mobile: 56px |
| Навыки: chips | До 3 + «+N», улучшен стиль чипов |
| Фильтр: справа в хедере | Desktop: сайдбар 250px фиксированный / mobile: drawer снизу |
| Кнопки: внизу карточки | Улучшены: `w-full` на mobile, иконки+текст |

### Адаптивные брейкпоинты
- **Mobile (<640px)**: 1 колонка, фильтр-drawer
- **Tablet (640-1024px)**: 2 колонки, фильтр сверху сворачиваемый
- **Desktop (>1024px)**: 3 колонки + сайдбар фильтра 250px

### Фильтр-drawer (mobile)
- `fixed inset-0 z-50`
- Оверлей: `bg-black/50 backdrop-blur-sm`
- Контент: `bg-white rounded-t-3xl p-6 max-h-[80vh] overflow-y-auto`
- Кнопки: «Применить», «Сбросить»

## Порядок реализации
1. `my_applications.html` — самый сложный (контакт-пейволл, масс-действия)
2. `my_jobs.html` — табы, статусы, масс-действия
3. `favorites.html` — сетка, пустое состояние
4. `chats_list.html` — превью, индикаторы
5. `workers.html` — фильтр-drawer, сетка

## Что НЕ трогаем
- `base.html` — общий макет
- `_icons.html` — макросы иконок
- `_filter_skills.html` — фильтр навыков (только на workers может потребоваться drawer-обёртка)
- `static/js/*.js` — JavaScript (favorites.js, applications.js)
- `app/blueprints/*.py` — серверная логика
- Миграции БД
