## Обнаруженные расхождения с текущим кодом

### 1. Неверный переход статусов заданий (критично)
- **Текущее поведение:** `active → completed` (мой коммит `e2d0494`)
- **Требование матрицы:** `active → payment_pending → paid → completed`
- **Исправление:** Вернуть `_maybe_set_job_payment_pending` к установке `payment_pending`, а не `completed`

### 2. Отсутствует статус `paid` для заданий (критично)
- Матрица требует переход `payment_pending → paid` при подтверждении обеими сторонами, затем `paid → completed`

### 3. Кнопки действий в шаблонах не соответствуют матрице
- `my_jobs.html`: нужно проверить, что для каждого статуса отображаются только разрешённые операции
- `job_detail.html`: нужно проверить кнопки для трудника по статусам

### 4. Неполные уведомления (секция 9)
- Отсутствуют уведомления о создании смены, чек-ине, завершении смены

### 5. Блокировки операций (секция 6)
- Нужно добавить проверки: нельзя отозвать задание с активными сменами, предупреждение за 12 часов до начала

## План реализации

### Шаг 1: Исправить `_maybe_set_job_payment_pending` в shifts.py
- Вернуть установку `payment_pending` вместо `completed` для заданий
- Shift переход: `pending → active → payment_pending → paid → completed`

### Шаг 2: Обновить `_handle_confirm_payment` в shifts.py
- При подтверждении обеими сторонами: shift → `paid`
- Job → `paid` если все shifts оплачены (НЕ `completed`)

### Шаг 3: Добавить переход `paid → completed`
- В `_handle_confirm_payment`: после установки `paid`, если все shifts paid → job → `completed`
  (УЖЕ ЕСТЬ в строке 168-170, но использует `supabase_request`; нужно `supabase_admin_request`)

### Шаг 4: Проверить и исправить шаблоны
- `my_jobs.html`: проверить кнопки по матрице секции 3.1
- `job_detail.html`: проверить кнопки для трудника по секции 4.1
- `shifts.html`: проверить кнопки по секции 4.2

### Шаг 5: Добавить недостающие уведомления (секция 9)
- Создание смены → труднику
- Чек-ин → работодателю
- Завершение смены → работодателю

### Шаг 6: Добавить блокировки (секция 6)
- Проверка active shifts перед отзывом задания
- Предупреждение за 12 часов до начала смены
