# Логи для проверки

## Проверка на PythonAnywhere

### 1. Проверьте логи ошибок
```bash
cd ~/mysite
cat error_log
```

### 2. Проверьте, что приложение перезапустилось
```bash
ls -la app.py.wsgi
```

### 3. Проверьте версию кода
```bash
cd ~/mysite
git log --oneline -3
```

## Проверка на Supabase

### 1. Проверьте структуру таблицы jobs
```sql
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'jobs' 
ORDER BY ordinal_position;
```

### 2. Проверьте наличие полей max_workers и current_workers
```sql
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'jobs' 
AND column_name IN ('max_workers', 'current_workers');
```

### 3. Проверьте данные в таблице
```sql
SELECT id, organization_name, max_workers, current_workers, status 
FROM jobs 
ORDER BY created_at DESC 
LIMIT 5;
```

## Возможные проблемы

### Проблема: Поле max_workers не отображается
**Решение:**
1. Проверьте, что миграция выполнена на Supabase
2. Проверьте, что `git pull` успешно завершился на PythonAnywhere
3. Выполните `touch app.py.wsgi` для перезапуска приложения

### Проблема: Ошибка "column max_workers does not exist"
**Решение:**
1. Выполните миграцию `migrations/add_max_workers.sql` на Supabase
2. Проверьте, что команда выполнилась без ошибок

### Проблема: Кнопка "Создать задание" не работает
**Решение:**
1. Проверьте логи ошибок (`cat error_log`)
2. Выполните `touch app.py.wsgi`
3. Проверьте, что все зависимости установлены (`pip install -r requirements.txt`)
