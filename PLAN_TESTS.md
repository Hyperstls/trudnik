# План тестирования функций приложения "Трудник"

## 1. Тестирование основных функций

### 1.1 Публичные страницы
- [ ] Проверить главную страницу (/)
- [ ] Проверить страницу работников (/workers)
- [ ] Проверить страницу входа (/login)
- [ ] Проверить страницу регистрации (/register)

### 1.2 Регистрация
- [ ] Зарегистрировать нового работника
- [ ] Зарегистрировать нового работодателя

### 1.3 Вход в систему
- [ ] Войти как работодатель
- [ ] Войти как работник

### 1.4 Профиль
- [ ] Проверить личный профиль (/profile)
- [ ] Обновить данные профиля

### 1.5 Задания (для работодателя)
- [ ] Создать новое задание (/create-job)
- [ ] Проверить страницу моих заданий (/my-jobs)
- [ ] Отредактировать задание

### 1.6 Отклики (для работника)
- [ ] Откликнуться на задание (/apply/<job_id>)
- [ ] Проверить отклики (для работодателя /my-applications)
- [ ] Принять отклик
- [ ] Отклонить отклик

### 1.7 Избранное и чёрный список
- [ ] Добавить в избранное
- [ ] Добавить в чёрный список

## 2. Последовательность тестов

1. Запустить браузер и проверить главную страницу
2. Зарегистрировать работника (test_worker@test.com / Test123456)
3. Зарегистрировать работодателя (test_employer@test.com / Test123456)
4. Войти как работодатель и создать задание
5. Выйти и войти как работник
6. Откликнуться на задание
7. Выйти и войти как работодатель
8. Проверить отклики и принять отклик

## 3. Ожидаемые результаты

- Все страницы должны загружаться без ошибок
- Формы должны принимать ввод
- Действия (кнопки) должны работать
- Уведомления (flash) должны отображаться
