## 1. Цель (goal)

Cooldown сброса/ресенда и IP-лимиты регистрации/сброса/ресенда используют общий cache; при недоступности cache auth-эндпоинты fail-closed с сообщением.

## 2. Критерии приёмки

1. Cooldown сброса/ресенда хранится в django cache (Redis в проде), не в памяти процесса.
2. 11-й POST /register с одного IP за час блокируется сообщением.
3. При недоступности cache register/reset/resend fail-closed с сообщением, без 500 и без создания профиля.
4. Повторный reset/resend в пределах cooldown не отправляет второе письмо.
5. core.tests.test_auth_flows и core.tests.test_auth проходят.

## 3. Вне scope

- Не менять login/lockout (это P103).
- Не менять модель Profile, RPC, шаблоны.
