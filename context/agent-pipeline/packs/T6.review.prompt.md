Доказать, что текст вывода не влияет на вердикт: 'OK' + exit 1 = FAIL, 'ERROR' + exit 0 = PASS.

1. Первый прогон liar_ok (текст OK, exit 1) дал общий verify FAIL — зафиксировано в логе.
2. Проверка liar_error (текст ERROR, exit 0) сама PASS.
3. После удаления liar_ok из контракта verify PASS по exit-кодам.
