## 2. Критерии приёмки

1. RegisterForm содержит поля portfolio_link, contact, inn, is_self_employed, experience, desired_payment, skills; full_name ≤150, city ≤100.
2. Шаблон регистрации рендерит эти поля, ошибки и чекбоксы навыков.
3. Worker-регистрация сохраняет все поля в Profile и навыки в UserSkill.
4. Employer-регистрация сохраняет city/portfolio_link/consented_at, но не сохраняет worker-only поля и навыки.
5. core.tests.test_auth_flows проходит.
