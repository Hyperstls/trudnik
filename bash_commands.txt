# КОМАНДЫ ДЛЯ PYTHONANYWHERE BASH CONSOLE
# Скопируйте и выполните эти команды в Bash console на PythonAnywhere

# 1. Перейти в директорию
cd /home/hyperstls

# 2. Создать резервную копию
cp app.py app.py.backup.20260603

# 3. Скачать обновлённый файл с GitHub
# Замените URL на реальный URL вашего файла
# Пример: curl -o app.py https://raw.githubusercontent.com/USERNAME/REPO/main/app.py
curl -o app.py https://raw.githubusercontent.com/Hyperstls/trudnik/main/app.py

# 4. Проверить файл
wc -l app.py
head -30 app.py

# 5. Перезапустить приложение
touch app.py.wsgi

# 6. Проверить логи (если ошибка)
cat /var/log/hyperstls.pythonanywhere.com.error.log

# 7. Протестировать
python3 -c "import requests; r = requests.get('https://hyperstls.pythonanywhere.com'); print(r.status_code)"
