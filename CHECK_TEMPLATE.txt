# Инструкция для проверки на PythonAnywhere

## Проверьте файл job_new.html на PythonAnywhere

Выполните на PythonAnywhere:

```bash
cd ~/mysite/templates
cat job_new.html | grep -A 2 "Максимум работников"
```

Если вы увидите:
```
            <label class="block text-sm font-semibold text-gray-700 mb-1.5">Максимум работников</label>
            <input type="number" name="max_workers" value="1" min="1" class="w-full border border-gray-200 p-3 rounded-xl text-sm focus:ring-2 focus:ring-gold/30">
            <p class="text-xs text-gray-500 mt-1">Сколько работников нужно для этого задания</p>
```

То файл правильный и проблема в другом.

Если вы увидите **другое содержимое** или **ничего не увидите**, значит файл не обновился.

---

## Если файл не обновился

Попробуйте принудительно переписать файл:

```bash
cd ~/mysite
git checkout HEAD -- templates/job_new.html
touch app.py.wsgi
```

Затем повторите проверку.

---

## Если файл правильный, но поле не отображается

1. Откройте DevTools (F12) в браузере
2. Перейдите на вкладку Network
3. Обновите страницу (F5)
4. Проверьте, что файл `job_new.html` загружается с сервера (статус 200)
5. Проверьте, что в HTML коде есть поле `max_workers`

---

## Возможные причины

1. **Кэширование шаблонов** - PythonAnywhere может кэшировать шаблоны
2. **Синтаксическая ошибка в app.py** - если есть ошибка, Flask может использовать другой шаблон
3. **Неправильный путь к шаблону** - проверьте, что шаблоны в папке `templates/`
