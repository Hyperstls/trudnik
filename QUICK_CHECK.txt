# Быстрая проверка на PythonAnywhere

## Выполнено успешно:
- ✅ `git pull origin main` - завершился
- ✅ `cat templates/job_new.html | grep -A 2 "Максимум работников"` - поле есть в файле
- ✅ `touch app.py.wsgi` - выполнено

## Проверьте в браузере:

### 1. Откройте DevTools
- Нажмите **F12** или **Ctrl+Shift+I**
- Перейдите на вкладку **Console**

### 2. Проверьте Console на наличие ошибок
Если есть красные ошибки - это может быть причиной

### 3. Обновите страницу с полной очисткой кэша
- Нажмите **Ctrl+F5** (или **Ctrl+Shift+R**)
- Это очистит кэш браузера

### 4. Проверьте HTML код
- Правой кнопкой на странице → **Просмотр кода страницы** или **Inspect**
- Найдите поле с `name="max_workers"`

### 5. Проверьте Network
- В DevTools перейдите на вкладку **Network**
- Обновите страницу (F5)
- Найдите `job_new.html` - должен быть статус **200**

## Если поле все еще не видно

Попробуйте следующее на PythonAnywhere:

```bash
# Перезапустите приложение еще раз

rm -rf __pycache__

```

Затем обновите страницу в браузере с **Ctrl+F5**.
