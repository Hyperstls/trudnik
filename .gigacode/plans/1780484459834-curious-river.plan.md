# План исправления ошибок в проекте "Трудник"

## Обнаруженные критические ошибки

### 1. **Синтаксическая ошибка в app.py (строка 257)**
**Файл:** `app.py`  
**Строка:** 257  
**Описание:** Обрезанный код `user_id = get_current_user_id` без завершения. Это синтаксическая ошибка, которая остановит выполнение приложения.

```python
# Обнаруженный код:
@app.route('/profile/update', methods=['POST'])
@login_required
def profile_update():
    user_id = get_current_user_id"  # ← ОБРЕЗАННО
```

**Исправление:** Закончить строку `user_id = get_current_user_id()` или удалить всю функцию, если она дублирует `/profile/edit`.

### 2. **Отсутствующие шаблоны**
**Файлы:**
- `templates/jobs.html` (используется в маршруте `/jobs`)
- `templates/profile_edit.html` (используется в `/profile/edit`)

**Исправление:** Создать недостающие шаблоны на основе существующих шаблонов или удалить соответствующие маршруты.

---

### 3. **Несоответствие полей формы и структуры данных**
**Файл:** `templates/register.html`  
**Описание:** Форма отправляет `full_name`, но код ожидает `name`.

```html
<!-- register.html -->
<input type="text" name="full_name" placeholder="Полное имя">
```

```python
# app.py (register)
profile_data = {
    'id': user_id,
    'email': email,
    'name': name,  # ← Ожидается 'name', но приходит 'full_name'
    ...
}
```

**Исправление:** Привести имена полей в соответствие (изменить `name='full_name'` → `name='name'` или добавить `name = request.form.get('full_name')`).

---

### 4. **Несоответствие полей в profile_edit**
**Файл:** `app.py`  
**Описание:** Функция `profile_edit` использует `full_name`, но в `/profile` ожидается `full_name`. В `/profile/edit` используется `name`.

**Исправление:** Унифицировать использование `full_name` или `name`.

---

### 5. **Непроверенные переменные в шаблонах**
**Файлы:** `templates/index.html`, `templates/jobs.html`  
**Описание:** Использование `request.args.get()` без проверки на `None` (например, `request.args.get('payment_min')`).

---

### 6. **Проблемы с обработкой откликов**
**Файлы:** `templates/index.html`, `templates/jobs.html`  
**Описание:** В `index.html` есть ссылки на несуществующие маршруты:
- `/apply/{{ job.id }}`
- `/unapply/{{ job.id }}`
- `/favorite-job/{{ job.id }}`

**Проверка:** Убедиться, что все эти маршруты определены в `app.py`.

---

### 7. **Отсутствие обработки ошибок Supabase**
**Файл:** `app.py`  
**Описание:** Многие методы Supabase вызываются без `try-except`, что может привести к падению приложения при ошибках БД.

---

### 8. **Неиспользуемая функция**
**Файл:** `app.py`  
**Функция:** `profile_update()`  
**Описание:** Функция обрезана и дублирует `/profile/edit`.

---

### 9. **Отсутствие валидации данных**
**Файлы:** `app.py`, `config.py`  
**Описание:** Отсутствует проверка обязательных конфигурационных переменных (`SUPABASE_URL`, `SUPABASE_KEY`).

---

### 10. **Потенциальные SQL-инъекции**
**Файл:** `app.py`  
**Описание:** Несмотря на использование Supabase, следует проверить, что все параметры обрабатываются через API (не через raw SQL).
