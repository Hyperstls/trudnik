## План исправления системы избранного (фаворитов)

## Обзор

Исправить систему избранного, чтобы трудники могли добавляться/удаляться из избранного с правильным сохранением данных и обновлением UI, включая отображение полной информации о труднике (имя, город, навыки).

## Проблемы

1. **Кнопка "В избранное"** на странице трудников не переключается в "Удалить из избранного" и обратно
2. **Массовое удаление** со страницы избранного работает только в DOM, но не сохраняет изменения в базе данных
3. **Отображение данных** - на странице избранного отображаются только id, full_name, photo_url, rating (пропущены: city, skills, experience, desired_payment)
4. **Удаление одного** - ошибка "не удалось определить ID трудника"
5. **RLS политики** - отсутствуют для таблиц favorites и blacklists

## Ошибки и решения

### Ошибка: "не удалось определить ID трудника"
**Причина:** Сложная цепочка `btn.parentElement.parentElement.dataset.workerId` не работала надежно.

**Решение:** Использовать `card.dataset.workerId` после `btn.closest('.card')`.

### Ошибка: Массовое удаление не сохранялось в базе
**Причина:** Удалялись только DOM элементы без вызова API.

**Решение:** Вызвать `/api/favorites/remove-selected` и удалять карточки только после подтверждения.

### Ошибка: Не хватает данных на странице избранного
**Причина:** SQL query выбирает только 4 поля вместо полного профиля.

**Решение:** Добавить `city,skills,experience,desired_payment` в SELECT.

### Ошибка: RLS блокирует операции с избранным
**Причина:** Отсутствуют политики безопасности для таблиц `favorites` и `blacklists`.

**Решение:** Создать политики для каждой таблицы.
