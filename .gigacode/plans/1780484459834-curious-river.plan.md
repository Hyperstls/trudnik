## План реализации полной логики жизненного цикла задания

## Обзор

Реализовать полную логику жизненного цикла задания со следующими состояниями:
- `open` - задание опубликовано
- `in_progress` - задание в работе (начало смены)
- `active` - смена активна (чек-ин работника)
- `payment_pending` - ожидание подтверждения оплаты
- `paid` - оплата подтверждена
- `cancelled` - задание отозвано
- `disputed` - спор по оплате

## Полный жизненный цикл задания

```
open → in_progress → active → payment_pending → paid
```

### Операции:

1. **open** - задание опубликовано
   - Можно отредактировать
   - Можно отозвать
   - Можно дублировать
   - Можно удалить
   - Принимаются отклики

2. **in_progress** - задание в работе
   - Работник принят
   - Можно отменить работника (если >12 часов до начала)
   - Нельзя дублировать/удалить

3. **active** - смена активна
   - Работник чек-инился
   - Нельзя отменить работника

4. **payment_pending** - ожидание подтверждения оплаты
   - Работник завершил смену
   - Ожидается подтверждение от работодателя и работника

5. **paid** - оплата подтверждена
   - Можно оценить работника
   - Можно запросить спор
   - Нельзя отменить

6. **cancelled** - задание отозвано
   - Можно восстановить
   - Можно удалить
   - Нельзя принять отклики

7. **disputed** - спор по оплате
   - На рассмотрении администратора

8. **completed** - задание завершено
   - Завершено без оплаты

## Ошибки и решения

### Ошибка: "column is_read does not exist"

### Ошибка: Кнопка "Дублировать" не работала
**Решение:** Вынесены кнопки за пределы формы и добавлены JavaScript функции для AJAX запросов

### Ошибка: "Не выбрано ни одного задания" при дублировании
**Решение:** Добавлена проверка `if not job_ids:` в маршрут `/my-jobs/action`

### Ошибка: Конфликт форм
**Решение:** Использованы отдельные формы для кнопок действий или JavaScript функции

### Ошибка: Поле max_workers не отображается на сервере
**Решение:** Изменения закоммичены и отправлены на GitHub, требуется выполнить git pull и перезагрузить WSGI на PythonAnywhere

### Ошибка: Скапливание ненужных файлов в корне
**Решение:** Все ненужные файлы перемещены в папку `archive/`. Создана инструкция `ARCHIVE_INSTRUCTION.txt` для будущей архивации.
