# Редактирование документов (SitePage)

Все публичные документы (`/privacy`, `/terms`, `/safety`, `/faq`) редактируются
в админке: **Контент → Контентные страницы**. Запись из БД имеет приоритет над
fallback-шаблоном.

## Как править

1. Открыть страницу в `/admin/core/sitepage/`.
2. Изменить `title`/`content` (HTML).
3. Ниже формы — **живой предпросмотр**: он обновляется при вводе и рендерит
   содержимое в sandboxed iframe. Скрипты внутри HTML не выполняются.
4. Нажать «Сохранить» и затем «Посмотреть на сайте» — проверить реальную
   страницу с публичными стилями.
5. Для юридических документов: обновить номер редакции/дату в тексте и
   сохранить предыдущую редакцию в конце страницы, если это требуется.

## Ограничения

- Это HTML-редактор с предпросмотром, а не rich-text: классы, `<abbr>`,
  заголовки и вёрстка сохраняются как есть.
- Не вставляйте `<script>` — предпросмотр его заблокирует, а публичная CSP
  может не выполнить его на странице.
- `slug` после создания не меняется (первичный ключ).
- После правок шаблонов/стилей: `npm run build:css`; после деплоя — проверить
  страницу и запустить UX quality вручную.

