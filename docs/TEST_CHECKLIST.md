| APP-002 | Отклик: дубликат | Повторный POST `/apply/<job_id>` | HTTP 409 Conflict — «Вы уже откликались» |
| APP-003 | Отклик: своё задание | Employer → POST `/apply/<свой_job_id>` | HTTP 403 Forbidden |
| APP-004 | Отклик: чёрный список | Employer заблокировал Worker → Worker откликается | HTTP 403 Forbidden |

| APP-007 | Accept отклика | Employer → POST `/api/applications/<id>/accept` | RPC `accept_application`: статус='accepted', `current_workers++`, уведомление worker'у |
| APP-008 | Accept: последнее место | `max_workers=1`, 1 pending → accept | Статус задания → `completed` |
| APP-009 | Reject отклика | Employer → POST `/api/applications/<id>/reject` | RPC `reject_application`: статус='rejected', уведомление worker'у |
| APP-010 | Reopen отклика | Employer → POST `/api/applications/<id>/reopen` | Статус='pending', без rate-limit |
| APP-011 | Withdraw отклика | Worker → POST `/cancel-application/<id>` (>12ч до начала) | Запись удалена, `current_workers--` (если был accepted) |
| APP-012 | Withdraw: окно < 12ч | Worker → POST `/cancel-application/<id>` (менее 12ч до начала) | Ошибка — «Нельзя отозвать менее чем за 12 часов» |
| APP-013 | Массовый отклик | Worker → POST `/apply-selected` с массивом `job_ids` | Отклики созданы только на валидные задания, Flash «Откликнуто на X из Y» |
| APP-014 | Batch accept | Employer → POST `/api/applications/batch` (action=accept, до 50 id) | Массовое принятие, RPC для каждого |
| APP-015 | Batch: >50 элементов | POST `/api/applications/batch` с 51 id | HTTP 400 Bad Request |
| APP-016 | Race condition на последнее место | 10 одновременных POST `/apply` → 10 accept на `max_workers=1` | Только 1 accepted, `current_workers` не > 1 |

## 18. Edge Cases

| ID | Название | Шаги | Ожидаемый результат |
|----|----------|------|---------------------|

| EDG-007 | Файл > 5MB или .exe | Загрузить файл 6MB или .exe как аватар | Whitelist-ошибка (jpg/png/gif/webp/pdf) |
| EDG-008 | Дата задания в прошлом | Создать задание с датой «вчера» | Принято или ошибка валидации (зависит от реализации) |
