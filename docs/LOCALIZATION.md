# Локализация (RU/EN)

**Дата:** 2026-11-03
**Статус:** русский — основной; английский — полный интерфейс кабинета и публичных страниц.

## Как переключить язык

Переключатель **RU / EN** находится в подвале каждой страницы. Django
`LocaleMiddleware` хранит выбор в cookie `django_language` (и в сессии), URL
не получают языковой префикс. Язык по умолчанию — `ru`.

## Что переведено

- общие элементы: шапка, навигация, подвал, установка PWA, тосты, диалоги
  подтверждения, степперы форм;
- публичный контур: каталог заданий, карточка задания, вход, регистрация,
  восстановление пароля, FAQ, поддержка, страница приложения;
- кабинет: профиль, мои задания/отклики, чаты и поиск по чату, уведомления и
  настройки уведомлений, избранное, приглашения, чёрный список, трудники,
  работодатели, оценки, форма задания, отклики на задание, поиск;
- формы, ошибки валидации, flash-сообщения, подписи статусов моделей;
- письма подтверждения email, сброса пароля и смены email — на языке запроса.

Не переводятся: пользовательский контент (названия заданий, имена, сообщения
чата), юридические документы из `SitePage` (их текст — источник истины на
русском), уже сохранённые записи уведомлений (исторические данные).

## Файлы

- `djadmin/locale/en/LC_MESSAGES/django.po` — исходный каталог.
- `djadmin/locale/en/LC_MESSAGES/django.mo` — скомпилированный каталог (в git).
- `static/js/` — JS получает строки из `window.TRUDNIK_I18N`, который
  формируется в `base.html` через `{% translate %}`.

## Как добавить строку

1. В шаблоне: `{% translate "Текст" %}` (загрузить `{% load i18n %}`).
2. В Python: `gettext("Текст")` для runtime или `gettext_lazy` для
   labels/choices на уровне класса.
3. Добавить msgid/msgstr в `django.po` и пересобрать `.mo`.

Сборка каталога (нужен `polib` или системный `msgfmt`):

```bash
.venv\Scripts\python.exe -m pip install polib
.venv\Scripts\python.exe -c "import polib; p=polib.pofile('djadmin/locale/en/LC_MESSAGES/django.po'); p.save_as_mofile('djadmin/locale/en/LC_MESSAGES/django.mo')"
```

`django-admin makemessages` требует установленный GNU gettext; на Windows его
обычно нет, поэтому `.po` поддерживается вручную/скриптом.
