# Трудник – контекст проекта (актуально на 04.06.2026)

## Краткое описание
Веб-приложение для быстрого поиска временной подработки в религиозных организациях (храмы, церкви, мечети и т.д.).
Работодатели (настоятели, администраторы) публикуют задания, а зарегистрированные трудники находят разовую работу.

## Технологический стек
- **Backend**: Python 3.12 + Flask (Application Factory + Blueprints)
- **База данных**: Supabase (PostgreSQL) – REST API + Auth + Storage
- **Фронтенд**: HTML5 + Tailwind CSS (CDN) + Jinja2
- **Карты**: Яндекс.Карты (JavaScript API)
- **Хостинг**: Docker-контейнер на Amvera / любая Docker-совместимая платформа
- **Деплой**: Docker + GitHub, конфигурация в `Dockerfile`, `docker-compose.yml`, `amvera.yml`
- **Версионирование**: Git (информация о коммите отображается при клике на иконку 🤝 в шапке)
- **AI‑помощник**: веб-чат DeepSeek (открывается в браузере по адресу `http://localhost:11434`) – используется для генерации/правок кода и анализа ошибок
- **Архитектура**: Flask Application Factory (`create_app()`) + 13 Blueprints

## База данных Supabase (основные таблицы)
- **`profiles`** – пользователи (роль, навыки, вероисповедание, рейтинг, `photo_url`, `portfolio_link`)
- **`jobs`** – задания (включая `preferred_religion`, `max_workers`, `current_workers`)
- **`applications`** – отклики на задания
- **`messages`** – сообщения чата
- **`favorites`** – избранные пользователи (работодатели/работники)
- **`job_favorites`** – избранные задания
- **`blacklists`** – чёрный список
- **`ratings`** – оценки (1-5 звёзд) + комментарий
- **`notifications`** – уведомления (тип, заголовок, текст, `is_read`)
- **`invitations`** – приглашения трудников на задания
- **`push_subscriptions`** – подписки на Web Push
- **`email_log`** – журнал отправленных email

## Полный Roadmap (в порядке реализации)

### 🔜 Этап 1 – Профили, навыки, верификация
1. **Портфолио и навыки**
   - Загрузка ссылки на портфолио (реализовано ✅)
   - Выбор профессий из базового списка (уборка, пение, ремонт, преподавание и т.п.) – множественный выбор
2. **Вероисповедание**
   - Работник указывает вероисповедание / «не важно» (реализовано ✅)
   - Работодатель в задании указывает предпочтительное вероисповедание (реализовано ✅)
3. **Верификация сотрудников**
   - Механизм подтверждения личности/навыков (загрузка документа, флаг `verified` в профиле, ручное одобрение админом)
4. **Список работ и профессий**
   - Готовый перечень (уборка храма, пение на клиросе, ремонт икон, преподавание в воскресной школе и т.д.)
   - Возможность работодателю искать сотрудников по этим категориям

### 🔜 Этап 2 – Улучшение откликов и карточек трудников
5. **Карточка отклика (работодатель)**
   - Показывать имя, рейтинг, навыки, желаемую оплату
   - Клик по карточке → профиль трудника
   - Кнопка «Написать» в каждой карточке (открывает чат)
6. **Массовые операции над откликами**
   - Чекбоксы + кнопки «Принять выбранные», «Отклонить выбранные», «Отозвать принятие выбранных»
   - Выбор всех откликов одним кликом
7. **Отзыв принятого работника**
   - Кнопка «Отозвать работника» доступна, если до начала смены > 12 часов
   - Иначе – предупреждение «Отменить принятие можно не позднее чем за 12 часов до начала смены»
8. **Приглашение трудников (страница «Трудники»)**
   - Кнопка «Пригласить» в карточке трудника
   - Отправляет уведомление и создаёт отклик-приглашение
   - Работодатель может сам искать и приглашать соискателей, а не только ждать откликов

### 💬 Этап 3 – Коммуникация и чаты
9. **Кнопка «Написать»**
   - На странице задания (для работника) – открывает чат с работодателем
   - На странице «Смены» (для работника) – аналогично
10. **Список чатов**
    - Каждый чат привязан к конкретной смене
    - На странице «Чат» отображаются все чаты, разделённые по работодателям/работникам
    - Возможность удалить один или несколько чатов
11. **Обмен файлами в чате**
    - Загрузка изображений/документов (используем Supabase Storage)
12. **Автообновление чата**
    - Новые сообщения появляются мгновенно (Supabase Realtime, подписка на `messages`)

### ⭐ Этап 4 – Рейтинг, отзывы и избранное
13. **Оценка после завершения**
    - После того как обе стороны подтвердили оплату (статус `paid`), появляется кнопка «Оценить»
    - Оценка: 1–5 звёзд + текстовый отзыв (опционально)
    - Рейтинг отображается в профиле и в карточках
14. **Избранное**
    - Кнопка «⭐ В избранное» в карточке трудника (на странице «Трудники»)
    - После выполнения задания – быстрая кнопка «Добавить в избранное» в отзыве

### 🚀 Этап 5 – Монетизация и финальные штрихи
15. **Количество людей в задании**
    - Поле «Требуется человек» (`max_workers`) при создании задания
    - При принятии отклика счётчик автоматически уменьшается
    - Отображается и у работодателя, и у соискателя
16. **Внутренние уведомления**
    - Колокольчик с количеством непрочитанных уведомлений
    - События: новый отклик, новое сообщение, приглашение, оценка
17. **Монетизация**
    - Продумать механизм комиссии (например, 10% от суммы смены)
    - Добавить поле `commission_paid` в смену и логику списания
    - Пока без реальных платежей – только фиксация в интерфейсе

## Правила деплоя (обновления сайта)

### Деплой через Docker / Amvera
Проект использует контейнеризацию через Docker. Основные конфигурации в `Dockerfile`, `docker-compose.yml`, `amvera.yml`.

### Важные замечания
- Приложение запускается через Uvicorn: `uvicorn asgi:application --host 0.0.0.0 --port 80`
- Health check доступен по `/health`
- Новые Blueprint'ы автоматически регистрируются в `app/__init__.py`
- Все изменения в `app/blueprints/` не требуют дополнительных действий при деплое
