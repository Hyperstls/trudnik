## Осталось (приоритизировано)

### P2

1. **Избранное раздроблено.** В шапке «Избранное» ведёт только на задания; `/favorites/people` смешивает работодателей и трудников, ссылка всегда ведёт в `worker_detail`, нет роли, приглашения и массового удаления. Нужна единая страница с секциями «Работодатели / Трудники / Задания» и действиями.
2. **Push-уведомления не подключены.** `static/js/push-notifications.js` есть и эндпоинты `/push/*` есть, но скрипт не подключён ни в одном шаблоне, а `_getCSRFToken()` читает cookie `csrf_token` вместо Django `csrftoken` — при включении подписка получит 403. Нужно подключить менеджер в настройках уведомлений и добавить кнопку «Включить push».
3. **«Мои отклики» упрощены.** Всегда открывается вкладка «Отправленные» (Flask открывает «Полученные», если есть свои задания); в карточках нет навыков, рейтинга, желаемой оплаты, «Выбрать все» и фильтра по навыкам.

### P3

4. **FAQ короче Flask:** 6 вопросов без тематических групп и CTA «Не нашли ответ».
5. **Чат:** нет разделителей по датам, пустого состояния и прокрутки вниз при открытии длинной истории.
6. **Карточка задания:** жалоба — постоянно видимый input вместо модалки; нет trust-блока «Безопасная сделка» и кнопки «Написать в чат» для принятого отклика.
7. **Legacy `/search`:** Flask редиректит на каталог; в Django маршрута нет — старые закладки дают 404.
8. **Уведомления:** нет human-подписей по типу и deep-link на приглашения; сейчас только title/message/date.
9. **Пустое избранное:** нет CTA «Найти задания/трудников».

## Осознанные решения (не баги)

- Контакты на публичных `/workers` и `/jobs` скрыты (152-ФЗ); открываются после отклика — J038.
- P2-04: после создания задания Django ведёт на detail, а не в «Мои задания».
- P2-07: в форме задания оставлены `org_description`/`object_description` (Flask оставлял пустыми) — осознанное UX-улучшение.
- P2-09: `/jobs/<id>/applicants` доступен админу (`admin_required` разрешён AGENTS.md).
- Карта трудников не делается: у `Profile` нет координат (J026 blocked), и по требованию пользователя на карте только офлайн-задания.
