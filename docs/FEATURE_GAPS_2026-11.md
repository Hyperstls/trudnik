# Аудит функций и страниц (2026-11-03)

Область: приложение бесплатное, монетизация/платежи/подписки **вне scope**.
Ниже — то, чего не хватает по фактическому коду, а не по legacy-документации.

## P1 — стоит сделать до активного роста

| Страница | Чего не хватает | Почему важно |
|---|---|---|
| `/profile` | Смена email с подтверждением | Email — логин; сейчас поле только показывается, ошибку в адресе исправить нельзя |
| `/employers/<id>`, `/profile` | Редактирование и публичный показ карточки работодателя (`EmployerDetail`: название, описание, адрес, ИНН) | Сейчас карточка меняется только в админке; шаблон `/employers/<id>` обращается к несуществующему `Profile.organization_name` и показывает пустоту |
| `/my-applications`, `/jobs/<id>` | Подтверждение выполнения со стороны трудника | Сейчас только работодатель делает `force_complete`; нет взаимного подтверждения/спора |
| Глобально | Страница поддержки/обратной связи | Есть жалоба на пользователя и email в документах, но нет обычной формы «написать в поддержку» |
| Глобально | Кастомные 404/500 | Сейчас стандартные страницы Django без навигации и бренда |

## P2 — заметно улучшит продукт

| Страница | Чего не хватает |
|---|---|
| `/workers/<id>` | `portfolio_link` сохраняется, но не выводится; отзывы есть на `/ratings/user/<id>`, но с профиля нет блока/ссылки |
| `/workers`, `/workers/<id>` | Нет поля сообщения при приглашении (модель `Invitation.message` есть, форма его не отправляет) |
| `/workers` | Нет фильтра «только приглашённые» и быстрого отзыва по конкретному заданию (сейчас отзыв всех pending для трудника) |
| `/my-jobs`, `/jobs/<id>` | Работодатель не видит статистику по заданию: просмотры, конверсию в отклик, источники |
| `/jobs/new`, `/jobs` | Нет признака «удалённая работа» и фильтра по нему |
| `/chat/<id>` | Только текст: нет вложений/фото, нет отметки прочтения |
| Шапка desktop | Нет ссылки «Мои задания» (на мобильной нижней навигации она есть) |
| `/profile` | Нет предпросмотра «как меня видят»; аватар можно загрузить, но нельзя удалить |

## P3 — после запуска/по желанию

- Двухфакторная аутентификация и управление сессиями.
- Отдельная страница сохранённых поисков (сейчас управление на `/jobs` и в настройках уведомлений).
- Когорты/UTM в аналитике.
- Публикация в RuStore/Google Play, iOS-инструкция.
- Баннер cookie-consent, если потребуется юридически.

## Осознанно не делаем

- Платежи, тарифы, продвижение, подписки — монетизация отложена.
- Карта трудников (J026) — у профиля нет координат; на карте только офлайн-задания.
