# Аудит функций и страниц (2026-11-03)

Область: приложение бесплатное, монетизация/платежи/подписки **вне scope**.
Ниже — то, чего не хватает по фактическому коду, а не по legacy-документации.

## Сделано 2026-11-03 (J144–J146)

- **Смена email** в `/profile`: пароль + письмо-подтверждение на новый адрес
  (токен 1 час), уведомление на старый email.
- **Карточка работодателя** (`EmployerDetail`) редактируется в `/profile` и
  показывается на `/employers/<id>`: название, компания, описание, город, адрес.
- **Страница `/support`**: форма обращения (имя, email, тема, сообщение),
  отправка на `SUPPORT_EMAIL`, ссылка в футере.
- **Кастомные 404/500** в брендовом стиле, с навигацией и поддержкой.
- **`/workers/<id>`**: портфолио и блок последних отзывов; приглашение с
  сообщением; ссылка «Мои задания» в desktop-меню; предпросмотр своего
  публичного профиля из `/profile`.
- **`/jobs/<id>` для владельца**: сводка откликов (всего/ожидают/принято/
  отклонено); **`/profile`**: удаление аватара.

## P1 — осталось до активного роста

| Страница | Чего не хватает | Почему важно |
|---|---|---|
| `/my-applications`, `/jobs/<id>` | Подтверждение выполнения со стороны трудника | Сейчас только работодатель делает `force_complete`; нет взаимного подтверждения/спора. Требует RPC/схемы — отдельная задача |

## P2 — заметно улучшит продукт

| Страница | Чего не хватает |
|---|---|
| `/workers` | Нет отзыва по конкретному заданию (сейчас отзыв всех pending для трудника); фильтр «только приглашённые» добавлен |
| `/jobs/new`, `/jobs` | Нет признака «удалённая работа» и фильтра по нему |
| `/chat/<id>` | Только текст: нет вложений/фото, нет отметки прочтения |

## P3 — после запуска/по желанию

- Двухфакторная аутентификация и управление сессиями.
- Отдельная страница сохранённых поисков (сейчас управление на `/jobs` и в настройках уведомлений).
- Когорты/UTM в аналитике.
- Публикация в RuStore/Google Play, iOS-инструкция.
- Баннер cookie-consent, если потребуется юридически.

## Осознанно не делаем

- Платежи, тарифы, продвижение, подписки — монетизация отложена.
- Карта трудников (J026) — у профиля нет координат; на карте только офлайн-задания.
