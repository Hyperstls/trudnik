# Информационная страница `/info`

## Что это

Публичная страница с объявлениями, новостями и полезными материалами:
заголовок, тип карточки, текст, опциональная кнопка-ссылка. Закреплённые
объявления показываются первыми, затем свежие.

- Страница: `/info` (и `/info/`).
- Вход: ссылка «Информация» в футере.
- Языки: RU/EN (строки в `django.po`/`django.mo`).

## Как добавить объявление

1. Открыть `/admin/core/announcement/` под staff-аккаунтом.
2. «Добавить объявление»:
   - **тип**: `news` (Новость), `event` (Событие) или `link` (Ссылка);
   - **заголовок**: до 200 символов;
   - **текст**: обычный текст, переносы строк сохраняются; HTML не
     интерпретируется (экранируется);
   - **ссылка**: только `http://` или `https://`;
   - **подпись ссылки**: текст кнопки, по умолчанию «Открыть»;
   - **закреплено**: поднимает карточку над остальными;
   - **активно**: снятый флаг скрывает карточку со страницы.
3. Сохранить. Страница обновляется без отдельной публикации.

## Модель

Таблица `announcements` (SQL-миграция `160_announcements.sql`), unmanaged
модель `core.models.Announcement`. Поля: `kind`, `title`, `body`, `url`,
`url_label`, `is_pinned`, `is_active`, `created_at`, `updated_at`.
`updated_at` обновляется триггером `trg_announcements_updated_at`.

## Безопасность и 152-ФЗ

- Страница публичная, но не содержит ПДн пользователей: только контент,
  который добавил staff.
- Текст экранируется шаблонизатором; `|safe` не используется.
- Ссылка допускается только с `http`/`https`, открывается с
  `rel="noopener noreferrer"`.
- IP, email и иные ПДн посетителей не сохраняются.
- Доступ к редактированию — только staff через Django admin.
