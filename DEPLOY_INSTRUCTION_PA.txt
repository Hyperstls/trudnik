## Деплой на PythonAnywhere:

### Шаг 1: Подключитесь к консоли PythonAnywhere
- Зайдите на https://www.pythonanywhere.com
- Откройте вкладку **Consoles**
- Создайте новую Bash консоль (или используйте уже открытую)

### Шаг 2: Выполните команды в консоли PythonAnywhere:

```bash
# Перейдите в директорию проекта
cd ~/mysite

# Получите последние изменения из GitHub
git pull

# Перезагрузите WSGI (обязательно!)
touch /var/www/hyperstls_pythonanywhere_com_wsgi.py
```

### Шаг 3: Проверьте результат

Откройте сайт в браузере: https://hyperstls.pythonanywhere.com

Перейдите на страницу создания задания: `/job/new`

Проверьте, что поле **"Максимум работников"** отображается корректно.

## Устранение проблем

### Если поле `max_workers` не отображается:

1. **Проверьте, что git pull выполнился успешно:**
   ```bash
   cd ~/mysite
   git status
   ```

2. **Проверьте, что файлы обновились:**
   ```bash
   cat templates/job_new.html | grep max_workers
   ```

3. **Попробуйте перезагрузить WSGI снова:**
   ```bash
   touch /var/www/hyperstls_pythonanywhere_com_wsgi.py
   ```

4. **Очистите кэш браузера** и попробуйте открыть страницу в Incognito режиме

### Если ошибка при git pull:

```bash
# Если есть конфликты, выполните:
git stash
git pull
git stash pop
```
