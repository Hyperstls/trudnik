## Ошибки и решения

### Ошибка: "column is_read does not exist"
**Решение:** Выполните миграцию `add_is_read_column.sql`

### Ошибка: "column max_workers does not exist"
**Решение:** Выполните миграцию `add_max_workers.sql`

### Ошибка: Кнопка "Дублировать" не работает
**Решение:** Убедитесь, что:
1. Миграция базы данных выполнена
2. Приложение перезапущено (touch app.py.wsgi)
3. Код обновлен через git pull
