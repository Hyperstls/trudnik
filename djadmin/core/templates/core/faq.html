{% translate "Как работает платформа разовой подработки «Трудник»" %}

{% translate "Регистрация и возможности" %}

{% translate "Как зарегистрироваться?" %}

{% translate "Нажмите «Регистрация», укажите имя, email и пароль. После регистрации подтвердите email по ссылке из письма — без подтверждения вход и часть функций недоступны. Если письмо не пришло, на странице входа есть «Не пришло письмо подтверждения?»." %}

{% translate "Можно ли и работать, и размещать задания?" %}

{% translate "Да. Любой аккаунт может откликаться на задания и создавать свои. При регистрации вы выбираете цель — «Искать подработку», «Размещать задания» или «И то, и другое»; это влияет только на стартовый экран, а не на доступ к функциям." %}

{% translate "Какие данные нужны для профиля?" %}

{% translate "Обязательно — имя и email. Дополнительно можно указать город, навыки, опыт, желаемую оплату и портфолио. ИНН указывается добровольно. Контакты не показываются публично: работодатель видит их после отклика. Экспорт и удаление данных — в «Профиле» (152-ФЗ)." %}

{% translate "Создание заданий" %}

{% translate "Как создать задание?" %}

{% translate "Нажмите «Создать» в шапке. Укажите вид работы, описание, адрес и город, дату и время, оплату и число работников. Для офлайн-задания поставьте точку на карте или найдите адрес — координаты нужны только для метки. Дистанционные задания можно создавать без карты." %}

{% translate "Сколько человек можно принять?" %}

{% translate "Число мест задаётся при создании. Когда все места заняты, приём откликов закрывается, а непринятые отклики отклоняются. Набор можно завершить досрочно кнопкой «Завершить»." %}

{% translate "Можно ли изменить или отменить задание?" %}

{% translate "Пока нет принятых откликов, доступно полное редактирование. После принятия работника можно менять только описание работы. «Отменить» снимает задание с публикации; отменённое задание можно восстановить, но прежние отклики при этом сбрасываются." %}

{% translate "Отклики и чат" %}

{% translate "Как откликнуться на задание?" %}

{% translate "Откройте задание и нажмите «Откликнуться». Работодатель увидит отклик в «Полученных» и сможет принять или отклонить его. Можно откликаться сразу на несколько заданий из ленты через чекбоксы." %}

{% translate "Когда открывается чат?" %}

{% translate "Чат доступен после принятия отклика. Работодатель может пригласить вас на задание — приглашение придёт в «Приглашения», где его можно принять или отклонить. Список «Чаты» показывает только принятые отклики." %}

{% translate "Можно ли отозвать отклик?" %}

{% translate "Да, кнопкой «Отозвать». Если до начала задания осталось менее 12 часов, отзыв недоступен — это защищает работодателя от срыва смены в последний момент." %}

{% translate "Безопасность и верификация" %}

{% translate "Как подтвердить профиль?" %}

{% translate "В профиле доступна верификация через MAX: перейдите по ссылке в чат с ботом и отправьте /start. Также можно загрузить документ в разделе «Верификация». Подтверждённые профили получают значок «Проверен»." %}

{% translate "Как пожаловаться на пользователя?" %}

{% translate "На странице профиля или задания нажмите «Пожаловаться» и опишите причину. Жалобы рассматривает администратор; при множественных жалобах аккаунт может быть приостановлен до разбирательства." %}

{% translate "Что делает чёрный список?" %}

{% translate "Заблокированный пользователь не сможет откликаться на ваши задания и не увидит их в ленте. Блокировку можно снять в разделе «Чёрный список»." %}

{% translate "Оплата" %}

{% translate "Сколько стоит платформа?" %}

{% translate "Сейчас все функции бесплатны: публикация заданий, отклики, чат, уведомления и поиск исполнителей. Платная монетизация отключена." %}

{% translate "Как происходит расчёт?" %}

{% translate "Оплата указывается в задании и происходит напрямую между работодателем и исполнителем. Платформа не выступает платёжным посредником и не удерживает комиссию. После завершения стороны могут оценить друг друга." %}
